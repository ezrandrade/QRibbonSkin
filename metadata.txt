about=QRibbonSkin 1.1.44 provides a reversible Ribbon interface for QGIS 4.x and preserves native tools and algorithms. ENABLE THE RIBBON: after installing and enabling the plugin in Plugins > Manage and Install Plugins, open View > Enable QRibbonSkin interface. DISABLE THE RIBBON: use Interface > Classic QGIS interface in the Ribbon, or press Ctrl+Alt+Shift+R to toggle between interfaces. In the classic view, use View > Enable QRibbonSkin interface to enable it again. If necessary, use View > Recover QGIS toolbars. The choice is remembered for the next QGIS session. Includes adaptations for the Layout Designer, Georeferencer and Processing Model Designer. Brazilian Portuguese and English supported. ArcSkin-derived visual assets are credited in ATTRIBUTION.md.
about[pt_BR]=O QRibbonSkin 1.1.44 oferece uma interface Ribbon reversível para QGIS 4.x, preservando as ferramentas e os algoritmos nativos.
